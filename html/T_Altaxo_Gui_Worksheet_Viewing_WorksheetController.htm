AdjustXScrollBarMaximum Recalculates the maximum value of the horizontal scroll bar.
AdjustXScrollBarViewPortSizeAdjusts the X scroll bar viewport size (= size of the thumb). Should be called after the X scrollbar maximum is adjusted or when the width of the columns changes considerably. Here, we want to avoid that the thumb size changing while we scroll through the worksheet. Thus, we calculate an average value for the thumb size that is the relation of the table-area width and the total width of all data columns.
AdjustYScrollBarMaximum Recalculates the maximum value of the vertical scroll bar.
