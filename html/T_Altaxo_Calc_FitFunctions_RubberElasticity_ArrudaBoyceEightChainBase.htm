ArrudaBoyceEightChainBase Class

Implements the Arruda-Boyce eight-chain model for incompressible hyperelastic rubber-like materials. Strain energy density (statistical form): W = mu * lambdaM^2 * ( (lambdaChain/lambdaM) * InverseLangevin(lambdaChain/lambdaM) + ln( (InverseLangevin(lambdaChain/lambdaM)) / sinh(InverseLangevin(lambdaChain/lambdaM)) ) ) with the chain stretch lambdaChain = sqrt(I1 / 3). Differentiating W with respect to the principal stretch for each deformation mode gives the nominal (engineering) stress: P = (mu / 3) * (lambdaM / lambdaChain) * InverseLangevin(lambdaChain / lambdaM) * dI1/dLambda where dI1/dLambda depends on the loading mode (incompressibility assumed, J = 1). Parameters: mu - initial shear modulus (small-strain), e.g. in MPa lambdaM - locking stretch (chain limiting stretch), typically 1.5 - 8, must be > 1 lambda - applied principal stretch (lambda = 1 + engineering strain)
